> **Un clic. Aucune configuration. Pas d'internet. Aucun compte.** Un animal de compagnie IA hors ligne — un compagnon pour vos jours de solitude, quelqu'un à qui se confier… et oui, vous pouvez le tapoter pour vous défouler. Le modèle LFM2.5-350M tourne 100% en local via llama.cpp.

MoonPet est un animal de compagnie IA hors ligne qui vous tient compagnie. Racontez tout à Momo — il écoute et répond dans un anglais simple et chaleureux. Caressez-le, nourrissez-le, câlinez-le ; ou giflez-le, tapotez-le, pincez-le, lancez-le, avec des réactions tout en dessin animé. Le modèle de 229 Mo est inclus dans chaque téléchargement : Windows, Linux, macOS, Android.

## Caractéristiques

- **Chat confidence** — racontez tout à Momo (pont dictionnaire indonésien→anglais inclus)
- **Tendresse** — caresser, nourrir, câliner ; l'humeur et le lien grandissent
- **Tapotages (cartoon !)** — gifle/tapot/pincement/lancer, bleus et K.O., sans sang
- **Succès** — 11 à débloquer
- **100% hors ligne et privé** — pas de télémétrie, pas de réseau, pas de compte
- **Un seul clic** — modèle intégré : téléchargez et lancez

## Démarrage rapide

```bash
# Windows: extract the zip  -> click MoonPet.bat
# Linux:    extract the tar -> run ./moonpet
# macOS:    extract the tar -> sh moonpet.command
# Android:  install the APK
# The 229 MB AI model is already bundled inside every package.
```
