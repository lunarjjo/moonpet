> **ワンクリック。設定不要。インターネット不要。アカウント不要。** オフラインで動くAIペット — 孤独な日の相棒、悩みを打ち明ける相手…そしてもちろん、ストレス解消にちょっとぶたれても大丈夫。LFM2.5-350M モデルが llama.cpp 経由で100%ローカル動作します。

MoonPet はあなたに寄り添うオフラインAIペットです。モモに何でも話してください — 聞いて、温かいシンプルな英語で返答します。なでる、食べさせる、抱きしめる。あるいは、びんた・デコピン・つねる・投げる — アニメらしいリアクション付き。229MB のモデルは全パッケージに同梱：Windows / Linux / macOS / Android。

## 特徴

- **相談チャット** — モモに何でも話せる（インドネシア語→英語の辞書ブリッジ同梱）
- **愛情** — なでる・食べさせる・抱きしめる；気分と絆が育つ
- **ぶつける（カートゥーン！）** — びんた・デコピン・つねる・投げる、あざやK.O.、流血なし
- **実績** — 11種
- **100%オフライン＆プライベート** — 通信・アカウント一切なし
- **ワンクリック** — モデル同梱：ダウンロードして実行するだけ

## クイックスタート

```bash
# Windows: extract the zip  -> click MoonPet.bat
# Linux:    extract the tar -> run ./moonpet
# macOS:    extract the tar -> sh moonpet.command
# Android:  install the APK
# The 229 MB AI model is already bundled inside every package.
```
