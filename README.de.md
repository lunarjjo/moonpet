> **Ein Klick. Kein Setup. Kein Internet. Kein Konto.** Ein Offline-KI-Haustier — ein Begleiter für einsame Tage, jemand zum Zuhören… und ja, du darfst es auch stubsen, um Dampf abzulassen. Das Modell LFM2.5-350M läuft zu 100% lokal über llama.cpp.

MoonPet ist ein Offline-KI-Haustier, das dich begleitet. Erzähl Momo alles — es hört zu und antwortet in warmem, einfachem Englisch. Streichle es, füttere es, umarme es; oder ohrfeige, stupse, zwicke und wirf es — mit echten Comic-Reaktionen. Das 229-MB-Modell ist in jedem Download enthalten: Windows, Linux, macOS, Android.

## Funktionen

- **Vent-Chat** — erzähl Momo alles (Indonesisch→Englisch-Wörterbuch-Brücke inklusive)
- **Zuneigung** — streicheln, füttern, umarmen; Stimmung & Bindung wachsen
- **Stubsen (Cartoon!)** — Ohrfeige/Stups/Zwick/Wurf, Blutergüsse & K.O., kein Blut
- **Erfolge** — 11 freischaltbar
- **100% offline & privat** — keine Telemetrie, kein Netzwerk, kein Konto
- **Ein Klick** — Modell integriert: herunterladen und starten

## Schnellstart

```bash
# Windows: extract the zip  -> click MoonPet.bat
# Linux:    extract the tar -> run ./moonpet
# macOS:    extract the tar -> sh moonpet.command
# Android:  install the APK
# The 229 MB AI model is already bundled inside every package.
```
