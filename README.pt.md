> **Um clique. Sem configuração. Sem internet. Sem conta.** Um bichinho de IA offline — um companheiro para os dias de solidão, alguém com quem desabafar… e sim, você pode dar uns cascudos para aliviar o estresse. O modelo LFM2.5-350M roda 100% local via llama.cpp.

MoonPet é um bichinho de IA offline que faz companhia. Conte tudo para a Momo — ela escuta e responde em inglês simples e acolhedor. Faça carinho, alimente, abrace; ou dê tapa, cascudo, beliscão e jogue-a, com reações de desenho animado. O modelo de 229 MB vem embutido em cada download: Windows, Linux, macOS e Android.

## Características

- **Chat de desabafo** — conte tudo para a Momo (ponte de dicionário indonésio→inglês incluída)
- **Carinho** — acaricie, alimente, abrace; humor e vínculo crescem
- **Cascudos (cartoon!)** — tapa/cascudo/beliscão/arremesso, hematomas e K.O., sem sangue
- **Conquistas** — 11 para desbloquear
- **100% offline e privado** — sem telemetria, sem rede, sem conta
- **Um clique só** — modelo embutido: baixe e rode

## Início rápido

```bash
# Windows: extract the zip  -> click MoonPet.bat
# Linux:    extract the tar -> run ./moonpet
# macOS:    extract the tar -> sh moonpet.command
# Android:  install the APK
# The 229 MB AI model is already bundled inside every package.
```
