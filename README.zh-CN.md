> **一键即用。无需配置。无需联网。无需账号。** 一只离线 AI 宠物 —— 孤独日子里的陪伴，可以倾诉的对象……当然，心情不好时也可以敲它出气。LFM2.5-350M 模型通过 llama.cpp 100% 本地运行。

MoonPet 是一只离线运行的 AI 宠物，随时陪着你。什么都可以跟 Momo 说 —— 它会倾听，并用温暖、简单的英语回应。摸摸它、喂喂它、抱抱它；也可以拍打、敲头、捏它、扔它 —— 全程卡通化反馈。229 MB 的模型已内置在每个安装包中：Windows、Linux、macOS、Android。

## 特性

- **倾诉聊天** —— 想说什么就说什么（内置印尼语→英语词典桥接）
- **关爱** —— 抚摸、喂食、拥抱；心情与羁绊会成长
- **敲打（卡通式！）** —— 拍打/敲头/捏/扔，淤青和 K.O.，绝无血腥
- **成就** —— 11 个可解锁
- **100% 离线且私密** —— 无遥测、无联网、无账号
- **一键即用** —— 模型已内置，下载即玩

## 快速开始

```bash
# Windows: extract the zip  -> click MoonPet.bat
# Linux:    extract the tar -> run ./moonpet
# macOS:    extract the tar -> sh moonpet.command
# Android:  install the APK
# The 229 MB AI model is already bundled inside every package.
```
