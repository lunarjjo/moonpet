> **Один клик. Без настройки. Без интернета. Без аккаунта.** Оффлайн-ИИ-питомец — компаньон для одиноких дней, кто-то, кому можно выговориться… и да, его можно и стукнуть, чтобы выпустить пар. Модель LFM2.5-350M работает на 100% локально через llama.cpp.

MoonPet — оффлайн-ИИ-питомец, который составляет вам компанию. Расскажите Момо что угодно — она слушает и отвечает тёплым простым английским. Гладьте, кормите, обнимайте; или шлёпайте, бодайте, щипайте и бросайте её — с мультяшными реакциями. Модель на 229 МБ уже внутри каждого пакета: Windows, Linux, macOS, Android.

## Возможности

- **Чат-исповедь** — расскажите Момо что угодно (включая индонезийско-английский словарный мостик)
- **Нежность** — гладить, кормить, обнимать; настроение и связь растут
- **Побить (мультяшно!)** — шлепок/бодание/щипок/бросок, синяки и нокаут, без крови
- **Достижения** — 11 штук
- **100% оффлайн и приватно** — ни телеметрии, ни сети, ни аккаунта
- **Один клик** — модель внутри: скачайте и запустите

## Быстрый старт

```bash
# Windows: extract the zip  -> click MoonPet.bat
# Linux:    extract the tar -> run ./moonpet
# macOS:    extract the tar -> sh moonpet.command
# Android:  install the APK
# The 229 MB AI model is already bundled inside every package.
```
