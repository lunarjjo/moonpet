MoonPet v0.1.0 — peliharaan AI offline: menemani kesepian, diajak curhat, dan boleh dipukul untuk melepas penat.

Otak: model LFM2.5-350M (Q4_K_M, 229 MB) berjalan 100% lokal lewat llama.cpp. Balasan chat bahasa Inggris sederhana — model kecil ini tidak dilatih untuk bahasa Indonesia; ketik bahasa apa pun, Momo menjawab dengan Inggris sederhana.

Dibuat oleh Lunar agent atas framework algoritma AI yang dikembangkan oleh @kasyaira. Model: LiquidAI LFM2.5-350M (LFM Open License v1.0). Runtime: llama.cpp (MIT). Aset visual digambar prosedural, tanpa aset pihak ketiga.

Pengguna tingkat lanjut: ganti berkas model/*.gguf dengan GGUF chat model lain (mis. multibahasa) lalu jalankan ulang — Momo otomatis ikut otak barunya.
