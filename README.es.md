> **Un clic. Sin configuración. Sin internet. Sin cuenta.** Una mascota de IA offline — una compañera para tus días de soledad, alguien a quien desahogarte… y sí, puedes darle un golpecito para liberar la tensión. El modelo LFM2.5-350M funciona 100% en local vía llama.cpp.

MoonPet es una mascota de IA offline que te acompaña. Cuéntale lo que quieras a Momo — escucha y responde en inglés sencillo y cálido. Acaríciala, dale de comer, abrázala; o dale una bofetada, un coscorrón, un pellizco o tírala, con reacciones de dibujo animado. El modelo de 229 MB va incluido en cada descarga: Windows, Linux, macOS y Android.

## Características

- **Chat para desahogarte** — cuéntale lo que quieras a Momo (puente de diccionario indonesio→inglés incluido)
- **Cariño** — acaricia, alimenta, abraza; el ánimo y el vínculo crecen
- **¡Golpecitos (cartoon)!** — bofetada/coscorrón/pellizco/lanzamiento, moretones y K.O., sin sangre
- **Logros** — 11 para desbloquear
- **100% offline y privado** — sin telemetría, sin red, sin cuenta
- **Un solo clic** — modelo incluido: descarga y ejecuta

## Inicio rápido

```bash
# Windows: extract the zip  -> click MoonPet.bat
# Linux:    extract the tar -> run ./moonpet
# macOS:    extract the tar -> sh moonpet.command
# Android:  install the APK
# The 229 MB AI model is already bundled inside every package.
```
