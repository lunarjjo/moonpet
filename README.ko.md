> **클릭 한 번. 설정 없음. 인터넷 없음. 계정 없음.** 오프라인 AI 펫 — 외로운 날의 친구, 털어놓을 수 있는 상대… 그리고 스트레스 풀려고 톡톡 때려도 OK. LFM2.5-350M 모델이 llama.cpp로 100% 로컬에서 동작합니다.

MoonPet은 당신 곁에 머무는 오프라인 AI 펫입니다. 모모에게 무엇이든 이야기하세요 — 들어주고 따뜻하고 간단한 영어로 답합니다. 쓰다듬고, 먹이고, 안아주세요; 아니면 살짝 때리거나, 콩 찍거나, 꼬집고, 던질 수도 있습니다 — 만화 같은 반응과 함께. 229MB 모델은 모든 패키지에 포함: Windows, Linux, macOS, Android.

## 특징

- **털어놓기 채팅** — 모모에게 뭐든 말하세요 (인도네시아어→영어 사전 브리지 포함)
- **애정** — 쓰다듬기, 먹이기, 안기; 기분과 유대가 자랍니다
- **톡톡 (만화!)** — 손바닥/콩/꼬집기/던지기, 멍과 K.O., 피 없음
- **도전 과제** — 11개
- **100% 오프라인 & 프라이버시** — 텔레메트리·네트워크·계정 없음
- **원클릭** — 모델 내장: 다운로드해서 바로 실행

## 빠른 시작

```bash
# Windows: extract the zip  -> click MoonPet.bat
# Linux:    extract the tar -> run ./moonpet
# macOS:    extract the tar -> sh moonpet.command
# Android:  install the APK
# The 229 MB AI model is already bundled inside every package.
```
